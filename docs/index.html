Radar Signal Processing Simulator

A pulse-Doppler radar chain that runs in your browser. It builds an LFM chirp, simulates echoes from Swerling targets, applies matched-filter pulse compression, runs the Doppler FFT, and detects targets with 2-D CA-CFAR. The same algorithms are in the tested C++17 library and the MATLAB script in the repo.
